---
title: "Ad Accounts"
description: "Manage ad accounts from various traffic platforms"
---

Ad accounts represent traffic sources — Facebook, Google, TikTok, etc.

## Fields

| Field | Description |
|-------|-------------|
| **Name** | Account display name |
| **Account ID** | Platform account ID |
| **Platform** | Traffic source platform |
| **Media Buyer** | Owner of the ad account |
| **Status** | Active, Paused, Disconnected, Risk Control, Disabled, Not In Use |

## Platforms

Facebook, Google Ads, TikTok Ads, Snapchat Ads, Native (Taboola, Outbrain), Email, Push, Display.

## Statuses

| Status | Description |
|--------|-------------|
| `active` | Active and receiving traffic |
| `paused` | Temporarily stopped |
| `disconnected` | Platform connection lost |
| `risk_control` | Under platform review |
| `disabled` | Permanently disabled |
| `not_in_use` | Created but not actively used |

## Spend Tracking

Record spend entries per ad account to track ROI and ROAS at the account level.
