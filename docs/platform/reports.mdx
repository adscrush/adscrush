## Performance Report

Group by: Product, Media Buyer, Advertiser, Campaign, Funnel, Creative, Source, Ad Account, Country, Device, OS, Browser, Date, Landing Page.

## Metrics

| Metric | Description |
|--------|-------------|
| Clicks | Total / Unique (24h dedup) |
| Conversions | Total / Approved |
| Revenue | Total revenue |
| Payout | Total payout to media buyers |
| Profit | Revenue minus payout |
| CR | Conversion rate |
| RPC | Revenue per click |
| EPC | Earnings per click |
| Spend | Ad spend (if tracked) |
| ROAS | Return on ad spend |

## Logs

- **Click Log** — Raw click data with geo, device, UTM, sub-IDs
- **Conversion Log** — Raw conversion data with event, status, payout
- **KPI Reports** — Pre-aggregated daily stats

## Export

Export performance, click log, or conversion log data to CSV.
