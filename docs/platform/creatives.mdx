Creatives are the visual and textual assets used in advertisements. AdsCrush tracks creative performance so you can optimize your best-performing variations.

## Creative Fields

| Field | Description |
|-------|-------------|
| **Name** | Creative display name |
| **Status** | Active / Inactive |
| **Campaign Links** | Which campaigns this creative is assigned to |

## Creative Files

Each creative can have multiple files (images, videos) stored on Bunny CDN. Files maintain:

- Sort order for display priority
- CDN URL for fast delivery
- Thumbnail URL for preview

## Creative Folders

Organize creatives into folders for easier management. Folders are hierarchical and custom to your team's workflow.

## Creative Notes

Add internal notes to creatives for team collaboration.

## Performance Tags

Tag creatives with performance labels for quick filtering and analysis.

## Campaign Assignment

Creatives are linked to campaigns (not the other way around). A creative can be in multiple campaigns. Each campaign-creative link is used for:

- Creative performance breakdown in campaign stats
- Creative-specific tracking links (`&cr=creativeId`)
- Attribution of clicks to specific creatives
