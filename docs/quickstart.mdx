title: "Quickstart"
description: "Get your first tracking link live in 5 minutes"
---

## 1. Create a Product

Products define payout terms and revenue models.

**Products** → **Create Product** → Fill in name, default payout, default revenue, currency → Save

## 2. Create a Funnel

Funnels hold your landing pages.

**Funnels** → **Create Funnel** → Link to product → Add landing pages with URLs (use `{tid}` macro) → Save

## 3. Create a Campaign

Campaigns wire together products, funnels, and ad accounts.

**Campaigns** → **Create Campaign** → Select funnel → Save

## 4. Assign an Ad Account

Open campaign → **Ad Accounts** tab → **Assign Ad Account** → Select ad account

A tracking link is auto-generated:

```
https://track.adscrush.com/c?c={campaignId}&aa={adAccountId}
```

## 5. Distribute Your Tracking Link

Share the link with your media buyer. When clicked, AdsCrush validates, records, and redirects to your landing page.
