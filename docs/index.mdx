Welcome to AdsCrush — a high-performance affiliate marketing and ad tracking platform. This documentation covers everything from dashboard usage to SDK integration and tracking setup.

## What is AdsCrush?

AdsCrush tracks clicks and conversions across advertising campaigns. It manages advertisers, media buyers (affiliates), ad accounts, creatives, and funnels — with real-time analytics to measure performance.

### Key Features

- **Click Tracking** — Every click captured with GeoIP, device detection, and UTM parameters
- **Conversion Tracking** — Track conversions via Web SDK, pixel, or server-side postback
- **Campaign Management** — Organize products, funnels, ad accounts, and creatives into campaigns
- **Funnel System** — Build funnels with weighted landing page selection
- **Real-Time Analytics** — Dashboards, performance reports, click logs, and conversion logs
